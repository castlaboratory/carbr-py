    Referência das funções¶

    Descobrir¶

    carbr.car_catalog(refresh=False) ¶

    O que está publicado: uma linha por UF.

    A versão, a origem e a citação ficam em df.attrs (version, source, citation). Zero linhas (com aviso) se a publicação não responder.

    Parameters:

    Name Type Description Default
    refresh bool

    Se True, ignora o catálogo em cache (válido por 6 horas).

    		 False

    carbr.car_dictionary() ¶

    Dicionário de dados: coluna publicada, nome no Sicar e descrição.

    carbr.car_summary(by='state', state=None) ¶

    Resumo pré-calculado.

    Contagem de imóveis e área declarada por qualquer combinação de UF, situação, porte, tipo, etapa da análise e ano de criação do cadastro. Lê tabelas pequenas, calculadas na publicação e guardadas em cache: responde em segundos mesmo para o país inteiro, sem ler os imóveis.

    Parameters:

    Name Type Description Default
    by str | Iterable[str] | None

    Dimensões do resumo, uma ou mais de "state", "status", "size_class", "property_type", "condition" e "created_year". None devolve uma linha só, com o total.

    		 'state'
    state str | Iterable[str] | None

    Sigla de uma ou mais UFs; None traz todas as publicadas.

    		 None

    Returns:

    Type Description
    DataFrame

    As colunas de by, properties (número de imóveis) e area_ha (área declarada, em hectares).

    carbr.car_municipalities(state=None) ¶

    Resumo por município.

    Imóveis, pequenos imóveis (até 4 módulos fiscais), área declarada, contagem por situação, geometrias inválidas e retângulo envolvente.

    Parameters:

    Name Type Description Default
    state str | Iterable[str] | None

    Sigla de uma ou mais UFs; None traz todas as publicadas.

    		 None

    Obter os imóveis¶

    carbr.car_properties(state, municipality=None, status=None, size_class=None, property_type=None, bbox=None, geometry=True) ¶

    Imóveis rurais declarados no CAR.

    Os filtros são aplicados antes da leitura: só os trechos do arquivo que os atendem são transferidos.

    Parameters:

    Name Type Description Default
    state str | Iterable[str]

    Sigla de uma ou mais UFs.

    		 required
    municipality

    Nomes ou códigos IBGE (7 dígitos) de municípios.

    		 None
    status

    "active", "pending", "suspended", "cancelled".

    		 None
    size_class

    "small" (até 4 módulos fiscais), "medium" (acima de 4 até 15), "large".

    		 None

    carbr.car_property(code, geometry=True) ¶

    Um ou mais imóveis pelo código (UF-0000000-identificador).

    carbr.car_check(code) ¶

    Verificar vários imóveis de uma vez.

    Para uma lista de códigos, diz o que consta de cada um na camada pública do CAR e resume em um resultado: a triagem que antecede, por exemplo, a análise de um pedido de crédito rural. Os códigos são agrupados por UF e município, de modo que uma lista grande lê poucos trechos de cada arquivo.

    O resultado (check) é uma classificação do pacote, não uma regra oficial:

    • "ok": cadastro ativo, sem notificação pendente;
    • "attention": cadastro pendente, analisado com notificação ainda sem resposta do declarante, com mais de 1% da área sobre terra indígena, unidade de conservação de proteção integral, floresta pública não destinada ou território quilombola georreferenciado no Sigef, ou com embargo ambiental ativo do Ibama;
    • "blocked": cadastro cancelado ou suspenso;
    • "not_found": código que não está na publicação (pode ter sido cadastrado depois da última atualização);
    • "invalid": texto que não tem o formato de um código do CAR.

    A sobreposição com terras indígenas (Funai) e unidades de conservação (CNUC/MMA) é calculada na publicação, pelos perímetros declarados. Estar em unidade de uso sustentável é informado na nota, mas não muda o resultado: áreas de proteção ambiental e reservas particulares admitem imóveis privados. Os embargos são os do Ibama (dados abertos, termos não cancelados e sem desembargo), localizados pelo polígono ou pelo ponto do termo; não entram embargos estaduais nem do ICMBio. A As florestas públicas não destinadas ("tipo B") são as do Cadastro Nacional de Florestas Públicas. Os territórios quilombolas são só os já georreferenciados no Sigef, do Incra: a camada completa não está publicada hoje, então a ausência de alerta não garante que o imóvel esteja fora de um território quilombola. A verificação não cobre a supressão de vegetação nem o trabalho análogo à escravidão, e não substitui a consulta oficial ao Sicar.

    Parameters:

    Name Type Description Default
    code str | Iterable[str]

    Códigos de imóvel no CAR (UF-0000000-identificador).

    		 required

    Returns:

    Type Description
    DataFrame

    Uma linha por código, na ordem dada: property_code, check, note (o motivo, em português), stage ("waiting", "analysing", "notified", "answered", "done" ou "cancelled"), status, condition, property_type, size_class, area_ha, fiscal_modules, state, municipality, created_at e, para os imóveis não cancelados, indigenous_share, strict_protection_share, sustainable_use_share (parcelas da área, de 0 a 1), protected_area (os nomes das áreas sobrepostas), embargo_count, embargo_share, public_forest_share, quilombola_share e sigef_share.

    carbr.car_at(lon, lat, state=None, geometry=True) ¶

    Imóveis que contêm um ponto.

    Responde "que imóveis estão declarados aqui?". O filtro pelo retângulo envolvente é feito na leitura remota e o teste exato, com o shapely (carbr[geo]). Sobreposições são comuns: pode vir mais de uma linha.

    carbr.car_tbl(state=None) ¶

    Relação preguiçosa do DuckDB sobre os imóveis.

    Para consultas que as outras funções não cobrem. Nada é lido até .df(); filter, project e aggregate viram leitura parcial do arquivo remoto. A geometria vem em WKB.

    Qualidade do cadastro¶

    carbr.car_quality(state, municipality=None) ¶

    Indicadores de qualidade por imóvel.

    Sinais calculados na publicação para cada imóvel não cancelado:

    • overlap_count e overlap_share: com quantos outros imóveis do estado ele divide área, e que parcela da área dele está sobreposta (a soma das interseções com cada vizinho, limitada a 1);
    • outside_share: que parcela da área fica fora do município declarado, pela malha municipal do IBGE;
    • indigenous_share: que parcela fica dentro de terras indígenas (Funai, todas as fases do processo), com o nome da principal em indigenous_land;
    • strict_protection_share e sustainable_use_share: que parcela fica dentro de unidades de conservação de proteção integral e de uso sustentável (CNUC/MMA), com o nome e a categoria da principal em conservation_unit e conservation_category (a de proteção integral, se houver);
    • embargo_count e embargo_share: quantos embargos ambientais ativos do Ibama alcançam o imóvel e que parcela da área está embargada (só os termos que têm o polígono da área; os demais contam pelo ponto de referência);
    • public_forest_share: que parcela fica dentro de florestas públicas não destinadas ("tipo B"), pelo Cadastro Nacional de Florestas Públicas, do Serviço Florestal;
    • sigef_count e sigef_share: quantas parcelas georreferenciadas no Sigef (Incra) o imóvel alcança e que parcela da área elas cobrem, contando só parcelas particulares e lotes de assentamento (glebas públicas e áreas protegidas, que também estão no Sigef, ficam de fora). Perto de 1 quer dizer que o perímetro declarado no CAR coincide com um georreferenciamento aprovado pelo Incra;
    • quilombola_share e settlement_share: que parcela cai em parcelas do Sigef cuja natureza é território quilombola ou assentamento. A cobertura é parcial: só os territórios já georreferenciados no Sigef; a camada completa de territórios quilombolas não está publicada pelo Incra hoje.

    Sobreposição entre imóveis não é sinônimo de disputa: inclui imóvel declarado duas vezes e lote dentro de assentamento; a comparação é só entre imóveis do mesmo estado. Estar em unidade de uso sustentável também não é irregularidade: áreas de proteção ambiental (APA) e reservas particulares (RPPN) admitem imóveis privados. As edições das camadas estão em source.protected_areas no catálogo.

    Parameters:

    Name Type Description Default
    state str | Iterable[str]

    Sigla de uma ou mais UFs.

    		 required
    municipality

    Nomes ou códigos IBGE (7 dígitos) de municípios; lê só os trechos deles.

    		 None

    Returns:

    Type Description
    DataFrame

    property_code, municipality_code e os indicadores acima. Junte a :func:car_properties por property_code. As colunas de terras indígenas e unidades de conservação vêm vazias se a publicação ainda não as traz.

    carbr.car_quality_summary(state=None) ¶

    Indicadores de qualidade por município.

    Para cada município: imóveis não cancelados (properties), quantos têm sobreposição acima de 1% (overlapping) e de 50% da área (overlapping_half), os hectares sobrepostos (overlap_ha, somando os dois lados de cada par), e quantos imóveis (outside_half) e hectares (outside_ha) ficam fora do município declarado. E, para terras indígenas (indigenous), unidades de proteção integral (strict_protection) e de uso sustentável (sustainable_use), quantos imóveis têm mais de 1% da área dentro delas e quantos hectares (*_ha); e quantos imóveis têm embargo ativo do Ibama (embargoed) e os hectares embargados (embargo_ha); e quantos têm mais de 1% da área em floresta pública tipo B (public_forest, public_forest_ha). Do Sigef: certified (imóveis com mais da metade da área em parcelas georreferenciadas), sigef_ha, quilombola e settlement (imóveis com mais de 1% em território quilombola ou em assentamento do Sigef). Arquivos pequenos, guardados em cache.

    Parameters:

    Name Type Description Default
    state str | Iterable[str] | None

    Sigla de uma ou mais UFs; None traz todas as publicadas.

    		 None

    Tipologia dos municípios¶

    carbr.car_typology(state=None) ¶

    Tipologia dos municípios.

    Cada município entra num de cinco grupos, pelo perfil do seu cadastro: o porte dos imóveis, em que etapa a análise está e quanto os cadastros se sobrepõem. Os grupos são achados por agrupamento (k-médias) sobre sete indicadores e ficam fixos de uma atualização para a outra, de modo que dá para acompanhar um município mudando de grupo. Municípios com menos de 30 imóveis não cancelados ficam em "few".

    Os indicadores, todos sobre os imóveis não cancelados do município:

    • small_share: parcela de imóveis pequenos (até 4 módulos fiscais);
    • large_area_share: parcela da área declarada que está em imóveis grandes;
    • waiting_share, notified_share e analysed_share: parcela aguardando análise, notificada sem resposta e já analisada ou em análise;
    • overlap_share: parcela com mais da metade da área sobreposta a outros cadastros;
    • coverage: área declarada dividida pela área do município (limitada a 2).

    Parameters:

    Name Type Description Default
    state str | Iterable[str] | None

    Sigla de uma ou mais UFs; None traz o país inteiro.

    		 None

    Returns:

    Type Description
    DataFrame

    Uma linha por município: state, municipality_code, municipality, typology (o código do grupo), typology_label (o nome), properties e os sete indicadores. O que cada grupo quer dizer está em :func:car_typology_groups.

    carbr.car_typology_groups() ¶

    Os grupos da tipologia dos municípios.

    Returns:

    Type Description
    DataFrame

    Uma linha por grupo: typology (o código), typology_label (o nome), description (o que o distingue), municipalities e properties (quantos municípios e imóveis estão nele na publicação atual).

    Citar¶

    carbr.car_cite() ¶

    Imprime e devolve a citação da versão publicada.

    A origem dos dados é o Sicar, do Serviço Florestal Brasileiro.

    Endereço, cache e opções¶

    carbr.set_base_url(url) ¶

    Define o endereço (URL ou pasta local) da publicação.

    Sem isso, vale a variável de ambiente CAR_URL e, na falta dela, o bucket público. None volta ao padrão.

    carbr.car_cache_dir() ¶

    Pasta de cache do carbr.

    Guarda o catálogo e o resumo municipal, uma pasta por versão. Os imóveis não são copiados: cada consulta lê do arquivo remoto só o que precisa.

    carbr.car_cache_clear() ¶

    Apaga o cache e devolve o caminho da pasta.

    carbr.set_timeout(seconds) ¶

    Tempo limite de cada requisição, em segundos (padrão 60).

    carbr.set_verbose(verbose) ¶

    Liga ou desliga as mensagens informativas.
